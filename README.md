# 🚀 SkillSetGo

> **AI-Powered Career Readiness Platform**

SkillSetGo is an AI-powered web platform that helps students and job seekers **build skills, prepare for interviews, improve communication, and become career-ready** — all in one place.

## ✨ Features

* 📄 **AI Resume Analysis** — Analyze resumes and identify skill gaps.
* 💻 **Technical Interview** — Practice AI-powered technical interviews.
* 🧠 **Topic-Based Interview** — Prepare for specific technologies and subjects.
* 🎯 **Behavioral Interview** — Practice HR and behavioral questions.
* 🗣️ **English Coach** — Improve English and communication skills using speech recognition.
* 📊 **Career Dashboard** — Track scores, strengths, and areas for improvement.
* 🗺️ **Personalized Roadmap** — Get a structured plan to improve career readiness.

## ⚙️ Run Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

Backend runs on:

```text
http://localhost:8000
```
